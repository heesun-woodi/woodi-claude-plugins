# 공신 출처 후보 매핑 (O8)

온보딩 O8에서 메인이 `상품·서비스`(개인은 주제) 텍스트를 보고 공신 출처 후보 3~6개를 제안할 때 참고하는 표입니다. 결과는 작업 폴더 `knowledge/official-sources.md`에 쓰고, `공지 페이지`가 있는 후보는 `knowledge/topic-seeds.md`의 `## 공지 소스`에도 넣습니다(SKILL.md O8·O11).

## 쓰는 규칙

1. `상품·서비스`의 각 항목을 아래 표의 `업종 키워드`(쉼표 목록)와 비교해 겹치는 행을 고릅니다. 뜻이 같은 말(예: 카페 ↔ 음료)도 겹침으로 봅니다.
2. 제안 순서: ① **법령 행**(아래 1행) — 업종에 면허·허가·신고·표시·안전 기준이 있으면 항상 넣습니다 ② 업종이 겹친 행(소관 부처 → 공공 포털 → 협회 순) ③ 공통 행(통계·소비자). 합쳐서 3~6개로 자릅니다.
3. 법령 행의 `<법령명>`은 메인이 **확실히 아는 법령 이름만** 채웁니다. 모르면 법령명을 지어내지 말고 「law.go.kr에서 「<업종 키워드>」 검색으로 소관 법령 확인」을 메모로 둡니다.
4. 이 표에 없는 기관은 사용자가 이름·주소를 알려 준 경우에만 추가합니다. 메인은 주소를 추측해 적지 않습니다 — 모르면 「기관 홈 검색」으로 둡니다.
5. 개인 유형은 후보가 없어도 됩니다. 그때는 「수치·통계를 쓰면 문장마다 출처 URL을 붙입니다」 정책만 쓰고 표는 업체 프로필 행만 둡니다.
6. 기관 이름·주소는 정부 조직 개편으로 바뀔 수 있습니다. 제안 표에 「접속해 확인 후 쓰기」를 한 줄 덧붙이고, 실제 접속 확인(접근성 기록)은 fact-checker가 처음 쓸 때 채웁니다.

`공지 페이지` 칸: 확실한 주소가 없으면 기관 홈에서 찾아가는 경로만 적습니다. `—`는 공지 소스로 쓰지 않는다는 뜻입니다.
