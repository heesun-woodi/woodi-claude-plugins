# 디자인 시스템 채우기 안내 (`[치환 변수]` → 값)

문서 본문의 **정본은 하나**다: 작업 폴더 `knowledge/design-system.md`(설치 때 플러그인 `scaffold/knowledge/design-system.md`가 복사된 것). 이 안내는 그 문서의 `[치환 변수]`를 무엇으로 바꾸는지만 정한다 — 문장·표·헤딩을 새로 쓰지 않는다(표지 1000×1000, `H2_FILLER_LINES`, ⑥ 마무리 순서, ⑦ 로테이션 같은 상세 규칙은 문서에 그대로 남는다).

- **치환 변수**: 인라인 코드(`` ` ``) 밖의 `[…]` 하나(`[[…]]`·`[글](url)`·`![](…)` 제외). SKILL 7단계 점검이 남은 개수를 센다 — 0이어야 한다.
- 수치 계산은 SKILL 5단계(값 출처 순서·공식 표), 측정은 2~3단계, 부록 A 조각은 4단계다. 여기에는 **어디에 무엇을 쓰는지**만 적는다.
- **★** = SKILL 「레퍼런스 0 없음」 경로(`role: own-style` 없음 — 자기 글 0편 블로그 포함). ★ 열이 비어 있으면 평소와 같다.
- 수치 뒤 근거 괄호는 `(값 출처 → 공식 → 값)` 형식. 측정해서 바꾼 수치는 괄호의 "측정 전"을 근거로 바꾼다. ★에서 lint 기본값을 그대로 둔 수치는 괄호를 `(초기값 = lint 기본값 — 측정 전)`으로 두고, 외부 레퍼런스 값이 있으면 `; 참고 레퍼런스 중앙값 <값>`만 덧붙인다(SKILL 5단계).
- `톤`에 맞지 않는 판(② **합니다체 판**/**해요체 판** 중 하나)은 판 제목·표·목록째 지운다. 판 위의 `<!-- … 판 하나만 남기고 … -->` 주석도 지운다. 정본 주석(첫 줄 아래)·④의 lint 블록·④의 수치 원칙 주석은 남긴다.
