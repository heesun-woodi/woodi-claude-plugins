[판 A — 프로필 `톤`이 합니다체일 때]
- 주 종결어미 = 합니다체(프로필 `톤` 결정). 한 문장은 짧게, 한 문단 2~4문장, 독자에게 말 걸듯.

| 구분 | 허용 종결 | 금지 종결 |
|---|---|---|
| 평서 | ~입니다 / ~합니다 / ~됩니다 / ~있습니다 | ~해요 / ~예요 / ~죠 / ~네요 |
| 권유 | ~하세요 / ~해 보세요 | ~해봐요 |
| 의문 | ~까요? / ~나요? / ~ㅂ니까?·~습니까? / ~인가요? / ~세요? | ~죠? / ~해요? |

- lint tone이 해요체 종결을 센다(FAIL).
- 예시 문장: (own-*.md에서 복사 + (logNo) — ★ 경로는 초기 예시)

[판 B — 프로필 `톤`이 해요체일 때]
- 주 종결어미 = 해요체(프로필 `톤` 결정, 친근한 말투). 한 문장은 짧게, 한 문단 2~4문장, 독자에게 말 걸듯.

| 구분 | 허용 종결 | 금지 |
|---|---|---|
| 평서 | ~해요 / ~예요·~이에요 / ~죠 / ~네요 / ~거든요 | 공문체(~하여야 한다 / ~할 것 / ~바랍니다) |
| 권유 | ~해 보세요 / ~해 봐요 | |
| 의문 | ~할까요? / ~나요? / ~죠? / ~인가요? (끝 제한 없음) | |
| 톤 섞기 | | 합니다체 종결(~습니다 / ~입니다 / ~됩니다)을 같은 글에 섞는 것 |

- 프로필 `톤`이 해요체면 lint tone은 합니다체 종결 문장 수를 WARN으로만 센다(통과에 영향 없음) — 섞지 않는 것은 글쓴이의 몫.
- 예시 문장: (own-*.md에서 복사 + (logNo) — ★ 경로는 초기 예시)
