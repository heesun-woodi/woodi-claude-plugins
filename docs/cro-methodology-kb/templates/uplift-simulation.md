# Uplift 시뮬레이션 템플릿

- **용도**: 가설의 Result 지표(선행지표)를 개선했을 때 매출 등 최종 KPI가 얼마나 증가하는지 추정 — 그루밍 ②단계 "비싼 문제 근거"와 ICE의 Impact 근거를 만드는 계산 구조
- **언제 배포**: 04챕터(PSR 가설) 그루밍 실습 또는 05챕터(ICE 우선순위) 세션에서, Impact 점수의 근거가 부족한 가설을 만났을 때
- **함께 쓰는 챕터**: `04_hypothesis-psr.md`(그루밍 ②Problem Validation — 비싼 문제 근거), `05_prioritization-ice.md`(Impact 점수 근거)

---

## ① 목적

가설의 Impact 점수는 "느낌"이 아니라 숫자로 방어할 수 있어야 한다. Uplift 시뮬레이션은 다음 질문에 답하기 위한 계산이다.

- 이 문제를 지금 해결하지 않으면 한 달에 얼마를 잃고 있는가
- Result 지표(선행지표)를 목표치까지 개선하면 매출이 얼마나 늘어나는가
- 보수적으로 봐도 이 실험을 할 가치가 있는가

이 표가 있으면 "이 실험을 안 하면 잃는 돈"을 숫자로 말할 수 있다. 의사결정권자 설득과 ICE의 Impact 근거 확보에 가장 강력하게 작동하는 산출물이다.

**주의**: 이 템플릿의 모든 수치는 가상 수치다. 실제 세션에서는 자사·고객사의 실측 데이터로 교체해서 쓴다.

---

## ② 입력값 표

| 입력 항목 | 값 | 비고 |
|---|---|---|
| 실험 영역 | | 개선하려는 퍼널 단계와 지면(예: PDP 중 특정 카테고리) |
| 데이터 기간 | 최근 30일 | 계절성이 큰 업종은 기간을 늘려 확인 |
| AOV (평균 주문 금액) | | 실험 영역 기준 AOV. 전사 평균과 다를 수 있음 |
| 기대 개선율 | | 솔루션이 개선하는 단계의 CVR **상대** 개선율(%). 그루밍 ⑤단계에서 정한 Target과 일치시킨다 |

**퍼널 단계별 Users** (실험 영역 기준, 데이터 기간 동안 실측)

| 단계 | Users | 단계 CVR (전 단계 대비) | 전체 CVR (최초 단계 대비) |
|---|---:|---:|---:|
| 1단계 (최초 진입) | | 100% | 100% |
| 2단계 | | | |
| 3단계 | | | |
| N단계 (구매/전환 완료) | | | |

> 영역별로 별도 계산이 필요하다. 카테고리·세그먼트가 다르면 퍼널 전체를 다시 뽑는다.

## ③ 계산 로직

아래 순서대로 계산한다. 스프레드시트에서는 각 Step을 한 행 또는 한 셀 그룹으로 두고 수식을 건다.

**Step A. 단계별 CVR 확정**

```
단계 CVR = 해당 단계 Users ÷ 이전 단계 Users
```

**Step B. 개선 후 eCVR (expected CVR) 산출**

```
eCVR = 기존 단계 CVR × (1 + 기대개선율)
```

**Step C. 개선 후 Users (해당 단계) 산출**

```
개선 Users = 이전 단계 Users(불변) × eCVR
```

**Step D. Delta Users (해당 단계)**

```
Delta Users = 개선 Users − 기존 Users
```

**Step E. 하류 단계 캐스케이딩**

개선한 단계보다 아래(하류)에 있는 단계들은, 그 아래 단계들의 CVR이 고정되어 있다는 가정 하에 같은 비율로 함께 증가한다.

```
하류 단계 개선 Users = 하류 단계 기존 Users × (eCVR ÷ 기존 단계 CVR)
```

이 가정을 반드시 워크시트에 명시한다 — 실제로는 개선된 유입자의 하류 전환율이 기존 유입자와 다를 수 있다(예: 배너를 보고 유입한 사용자가 구매 의향이 더 낮을 수 있음). 보수 시나리오에서는 하류 CVR을 소폭 할인해서 잡는 것을 권장한다.

**Step F. 추가 구매자 수 (Delta 구매자수)**

```
Delta 구매자수 = 구매 단계 개선 Users − 구매 단계 기존 Users
```

**Step G. 일 매출 증분**

```
일 매출 증분 = (Delta 구매자수 ÷ 데이터 기간 일수) × AOV
```

**Step H. 월 매출 증분**

```
월 매출 증분 = 일 매출 증분 × 30
```

검산: `월 매출 증분 = Delta 구매자수 × AOV` (데이터 기간이 30일이면 두 계산이 같은 값이어야 한다)

## ④ 3시나리오 표 (보수 / 기본 / 낙관)

기대개선율을 3단계로 나눠 계산한다. 실험 목표(Target)는 보통 낙관 시나리오에 대응한다.

| 시나리오 | 기대개선율 | eCVR | Delta Users (개선 단계) | Delta 구매자수 | 일 매출 증분 | 월 매출 증분 |
|---|---:|---:|---:|---:|---:|---:|
| 보수 | | | | | | |
| 기본 | | | | | | |
| 낙관 (실험 목표) | | | | | | |

---

## ⑤ 워크드 예시 (가상 수치 — 실제 고객 데이터 아님)

**시나리오 설정**: 가상 온라인 커머스, PDP → 장바구니 담기(A2C) 단계의 가시성 개선 실험

**입력값**

| 입력 항목 | 값 |
|---|---|
| 실험 영역 | PDP(특정 카테고리) |
| 데이터 기간 | 최근 30일 |
| AOV | 50,000원 |
| PDP Users (1단계) | 150,000 |
| A2C Users (2단계, 개선 대상) | 30,000 (CVR 20%) |
| 구매완료 Users (3단계) | 12,000 (A2C 대비 CVR 40%) |

**계산 (기본 시나리오, 기대개선율 25%)**

| Step | 계산 | 값 |
|---|---|---:|
| A. 기존 A2C CVR | 30,000 ÷ 150,000 | 20% |
| B. eCVR | 20% × (1 + 25%) | 25% |
| C. 개선 A2C Users | 150,000 × 25% | 37,500 |
| D. Delta Users (A2C) | 37,500 − 30,000 | 7,500 |
| E. 하류(구매) 캐스케이딩 — 구매 CVR 40% 고정 | 37,500 × 40% | 15,000 |
| F. Delta 구매자수 | 15,000 − 12,000 | 3,000 |
| G. 일 매출 증분 | (3,000 ÷ 30) × 50,000 | 5,000,000원 |
| H. 월 매출 증분 | 5,000,000 × 30 | 150,000,000원 |

검산: `3,000 × 50,000 = 150,000,000원` — G×30과 일치.

**3시나리오 전개**

| 시나리오 | 기대개선율 | eCVR | Delta Users(A2C) | Delta 구매자수 | 일 매출 증분 | 월 매출 증분 |
|---|---:|---:|---:|---:|---:|---:|
| 보수 | 15% | 23% | 4,500 | 1,800 | 3,000,000원 | 90,000,000원 |
| 기본 | 25% | 25% | 7,500 | 3,000 | 5,000,000원 | 150,000,000원 |
| 낙관 (실험 목표) | 35% | 27% | 10,500 | 4,200 | 7,000,000원 | 210,000,000원 |

**해석**: 보수적으로 봐도 월 9천만원 규모의 매출 증분이 기대된다. 이 정도 규모면 ICE Impact 점수를 상위(7~9점)로 방어할 수 있는 근거가 된다. "왜 Impact가 높냐"는 질문에 이 표 한 장으로 답한다.

## ⑥ 스프레드시트로 옮길 때의 팁

- **수식을 거는 셀**: eCVR, 개선 Users, Delta, 일/월 매출 증분 셀에는 반드시 수식을 걸어 입력값(Users·AOV·기대개선율)만 바꿔도 전체가 재계산되게 한다. 하드코딩된 숫자를 붙여넣지 않는다.
- **데이터 링크 칸을 따로 둔다**: 퍼널 데이터 출처(Mixpanel 리포트 URL 등), AOV 데이터 출처를 표 옆에 별도 셀로 남긴다. 나중에 숫자가 바뀌었을 때 어디서 다시 뽑아야 하는지 추적 가능해야 한다.
- **영역별 시트 분리**: 카테고리·세그먼트마다 퍼널과 AOV가 다르면 시트를 분리한다. 하나의 시트에 여러 영역을 섞으면 캐스케이딩 가정이 깨진다.
- **하류 CVR 고정 가정을 셀 주석으로 남긴다**: Step E의 가정(하류 CVR 불변)이 비현실적인 경우(예: 유입 품질이 달라지는 실험) 보수 시나리오의 하류 CVR을 별도로 할인해 입력한다.
- **3시나리오는 같은 시트, 다른 열로 구성**: 기대개선율만 바꿔서 3열을 나란히 두면 비교와 프레젠테이션이 쉽다.
- **연간 환산이 필요하면**: 월 매출 증분 × 12로 12개월 증분을 추가할 수 있다. 다만 계절성·트렌드가 큰 업종은 단순 12배가 아니라 최근 12개월 실측 트래픽으로 재계산을 권장한다.
