## 작성 예시 (참고용 — 가상 도서 구독 앱)

아래는 설명을 위해 지어낸 가상 예시다(업종·수치·발화 모두 실제 사례가 아니다). 회색으로 표시했으며, 실습 시 이 내용을 지우고 자신의 가설로 채운다.

<div style="color:#8a8a8a;">

**① 현재 가설**

> "검색 결과의 클릭률이 낮다"

이 문장은 공급자 언어 + 솔루션 없음 + 수치 없음 상태다. 그루밍을 거쳐 아래처럼 정리한다.

**② Problem 분해**

| 질문 | 답변 |
|---|---|
| 누가 | 책을 검색한 구독자, 특히 플랜 외 도서가 섞인 결과를 본 사용자 |
| 어디서 | 검색 결과 목록, 상세를 열기 직전 |
| 무엇을 | 어떤 책을 내 플랜으로 바로 읽을 수 있는지 구분하지 못해 다시 검색하거나 나간다 |
| 근거 | 검색 결과 → 책 상세 진입률이 탐색 경로 중 최저 구간 |

**③ Problem Validation**

| 유형 | 근거 | 출처·조회조건 |
|---|---|---|
| 정성 | 자체 UT에서 "이 책은 추가로 결제해야 하나요?"라는 질문 반복 | 자체 UT 5건 |
| 정량 | 플랜 외 도서가 섞인 검색 결과에서 재검색·이탈이 집중 | 코호트 분석(조회 기간을 함께 적는다) |
| 정량 | 검색 결과 → 책 상세 진입률이 탐색 경로 중 최저 구간 | 퍼널 분석(조회 기간을 함께 적는다) |

| 시나리오 | 지표 개선 | 월간 증분 | 최종 KPI 증분 |
|---|---|---|---|
| 보수 | 44% → 46% | 소폭 증가 (가상 수치, 상세 계산 생략) | 소폭 증가 |
| 기본 | 44% → 48% | 중간 증가 | 중간 증가 |
| 낙관 (실험 목표) | 44% → 50% | 최대 증가 | 최대 증가 |

**④ Solution**

| 구분 | 내용 |
|---|---|
| 현재안 | 검색 결과 카드에 「구독으로 바로 읽기」 표시를 붙이고 상세 바로가기를 둔다 |
| 대안 A | 검색 결과 상단에 「내 플랜에서 읽을 수 있는 책만 보기」 필터를 둔다 |
| 대안 B | 플랜에 포함되지 않은 책을 결과 하단으로 정렬한다 |

- `[x]` 경쟁사 레퍼런스 — 동종 구독 서비스 다수가 목록 카드에 이용 가능 여부를 표시
- `[ ]` 자사 과거 실험 — 해당 없음
- `[x]` UT·VOC — "이 책은 추가로 결제해야 하나요?" 질문 반복
- `[x]` 행동경제학 — Framing Effect("추가 결제 없음"을 카드에서 바로 확인하게 함)

Counter Rationale: 표시가 카드 정보를 늘려 목록 훑기 속도가 떨어지면 오히려 진입이 줄 수 있음 → 검색 결과 스크롤 깊이를 Secondary로 관찰

**⑤ Result**

| 항목 | 내용 |
|---|---|
| Result 지표 | 검색 결과 → 책 상세 진입률 |
| Baseline | 44% (가상 수치) |
| Target | 50% (가상 수치) |
| 목표 설정 방법 | 내부 Gap — 플랜 포함 도서만 나온 검색 결과에서의 동일 지표 수준 |

선행지표 자가 체크: 최종 KPI(읽기 시작·구독 유지)가 아니라 표시의 직접 반응인 "상세 진입"을 지표로 잡았다. `[x]`

**⑥ 그루밍 후 가설**

> "책을 검색한 구독자에게 검색 결과에서 내 플랜으로 바로 읽을 수 있는 책인지 알려주면, 검색 결과 → 책 상세 진입률이 44% → 50%로 증가할 것이다"

**⑦ 셀프 체크리스트**: 8개 항목 모두 충족 — 스프린트 후보로 5단계(ICE 스코어링) 이관 가능
