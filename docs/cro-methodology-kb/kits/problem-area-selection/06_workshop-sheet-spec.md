# 06. 워크숍 구글시트 8탭 구조 스펙

> **용도**: 워크숍 워크스페이스로 쓰는 공유 구글시트 1개의 **구조 정본**. 탭·섹션·컬럼·수식·서식·보호 규칙을 정의한다.
> **대상**: 준비 주간에 시트를 만드는 코치. 실행본은 [`scripts/build_workshop_sheet.py`](scripts/build_workshop_sheet.py)이며, **구조를 바꿀 때는 이 문서를 먼저 고치고 스크립트를 맞춘다.**
> **정합 원칙**: 각 섹션의 컬럼 순서 = [`02_analysis-prompt-cards.md`](02_analysis-prompt-cards.md) 카드 마지막 TSV 출력의 컬럼 순서. 이 1:1 정합이 깨지면 붙여넣기가 밀린다.

- S7·S8 수식 열은 회색이며 **경고 보호**가 걸려 있다.

## 3. 수식 스펙 (정본 — 그대로 구현)

### 3.1 S7 — Gap 배수 자동 계산

H열(8번째 열), 데이터 8행 각각:

```
=IF(OR(C{행}="",D{행}=""),"",ROUND(D{행}/C{행},2))
```

`C` = 현재 전환율, `D` = 벤치마크. **Gap은 %p가 아니라 배수**다. 카드가 낸 `Gap 배수(교차검증)`(G열)과 이 자동 배수가 다르면 **분모부터 의심**한다.

### 3.2 S8 — 기회손실 계산기

**입력 구획 6행** (컬럼: `입력값 항목` / `값` / `출처` / `가정`, 값·출처·가정은 노란 입력 셀).
아래에서 `TR`·`CU`·`BM`·`RES`·`VAL`·`MUL`은 각 입력 행의 **B열 시트 행 번호**다.

| 순서 | 입력값 항목 | 앵커 | 카드 4-3 A블록 |
|---|---|---|---|
| 1 | 영역 트래픽(월) | `TR` | ○ |
| 2 | 현재 전환율 | `CU` | ○ |
| 3 | 대표 벤치마크 (S6 대표 선택과 일치) | `BM` | ○ |
| 4 | 이후 퍼널 잔여 전환율 (개선 지점 이후 단계들의 곱) | `RES` | ○ |
| 5 | `[전환 가치 단가]` | `VAL` | ○ |
| 6 | 기간 배수 (기본 1, 배수 사용 시 가정 칸에 '미검증 가정') | `MUL` | ✕ (카드 TSV 밖 · 수동) |

**시나리오 구획 3행** (컬럼: `시나리오(자동)` / `목표 전환율` / `개선 대상 인원(월)` / `증분 전환 수(월)` / `증분 가치(월, 원)` / `연환산(원)`). 전 열이 수식(회색·경고 보호). `{r}` = 그 시나리오 행 번호.

| 시나리오 | B열 — 목표 전환율 |
|---|---|
| 보수 (Gap의 1/3) — **대표값** | `=IF(OR($B${CU}="",$B${BM}=""),"",ROUND($B${CU}+($B${BM}-$B${CU})/3,2))` |
| 중도 (Gap의 1/2) | `=IF(OR($B${CU}="",$B${BM}=""),"",ROUND($B${CU}+($B${BM}-$B${CU})/2,2))` |
| 낙관 (벤치마크 도달) | `=IF($B${BM}="","",$B${BM})` |

세 행 공통 수식 체인 (기회손실 3식의 시트 구현):

| 열 | 의미 | 수식 |
|---|---|---|
| C | ① 개선 대상 인원(월) | `=IF(OR($B${TR}="",B{r}=""),"",ROUND($B${TR}*(B{r}-$B${CU})/100,0))` |
| D | ② 증분 전환 수(월) | `=IF(OR(C{r}="",$B${RES}=""),"",ROUND(C{r}*$B${RES}/100,0))` |
| E | ③ 증분 가치(월, 원) | `=IF(OR(D{r}="",$B${VAL}=""),"",ROUND(D{r}*$B${VAL}*IF($B${MUL}="",1,$B${MUL}),0))` |
| F | 연환산(원) | `=IF(E{r}="","",E{r}*12)` |

전환율은 **% 숫자로 입력**한다(예: 12.5). 그래서 C·D 열에 `/100`이 들어간다.

**대조용 구획 3행** — 컬럼 `시나리오(대조용)` / `목표 전환율` / `증분 전환수(월)` / `연환산`. 카드 4-3 B블록(클로드가 계산한 값)을 붙인다. **수식 결과와 다르면 입력값을 의심하고 멈춘다.** 시트 계산기가 정본, 클로드 계산은 대조용이다.

## 6. 시트 운영 규칙

배포 전 이 3줄을 `0_HOME` 상단과 구두 안내에 동일하게 넣는다.

1. **시트가 정본입니다** — 클로드 창은 스크래치. 각 카드의 마지막 TSV 블록만 시트에 붙입니다.
2. **자기 구간 탭만 편집합니다** (구간 A 담당 → `2_구간A_분석` / 구간 B 담당 → `3_구간B_분석`). 공용 탭 기록은 코치·기록 담당이 합니다.
3. **노란 셀만 입력**, 회색 셀은 수식(덮어쓰기 금지). Gap은 %p가 아니라 배수로 씁니다. **정렬·필터 사용 금지**.

### TSV 붙여넣기 규칙 (요약)

- 카드 마지막 출력은 **헤더 포함 · 탭 구분 TSV**. 컬럼 순서 = 착지 섹션 컬럼 순서.
- 착지 섹션의 **헤더 행에 겹쳐** 붙인 뒤, 중복된 헤더 1줄을 지운다. (헤더 없이 받았다면 첫 데이터 셀에 붙인다.)
- 열이 안 나뉘면 붙인 범위 선택 → **데이터 → 텍스트를 열로 분할 → 구분자: 탭**.
- 마크다운 파이프(`|`) 표는 한 셀에 뭉개진다. 반드시 TSV로 다시 받는다.
- 숫자가 왼쪽 정렬(텍스트)로 붙으면 클로드에 `숫자 컬럼에서 쉼표·%·₩ 기호를 빼고 순수 숫자만 넣어 TSV를 다시 출력해줘`.
- 섹션 아래 **버퍼 3행**을 침범하지 않는다. 정리 전 원출력은 **K열 오른쪽 RAW 존**에 버린다.

## 7. 생성·재구축 절차

```bash
# 1) CONFIG를 브리프 값으로 수정
# 2) 실행
python3 scripts/build_workshop_sheet.py
```

- `CONFIG["ssid"]`가 **비어 있으면**: 새 스프레드시트를 만들고 ID를 출력한다 → 그 ID를 CONFIG에 넣어둔다. 생성에 실패하면 "기존 시트 ID를 CONFIG에 넣고 재실행" 안내를 출력하고 종료한다.
- `CONFIG["ssid"]`에 **값이 있으면**: 기존 탭을 삭제·재생성한다 — **URL이 유지**되므로 이미 공유한 링크를 그대로 쓸 수 있다.
- 재구축은 **입력값을 지운다.** 워크숍 시작 전에만 실행한다.
- 실행 후 리허설: 카드 1장을 실제로 돌려 TSV → 시트 붙여넣기가 **열 단위로 맞는지** 확인한다.
